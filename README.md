V免签(PHP) 是基于 ThinkPHP 5.1 + MySQL 实现的一套免签支付程序，主要包含以下特色：

+ 收款即时到账，无需进入第三方账户，收款更安全
+ 提供示例代码简单接入，超简单 Api 使用，统一 Api 实现收款回调
+ 支持监听店员收款信息，可使用支付宝/微信小号或模拟器挂机，方便 iOS 用户
+ 免 root、免 xp 框架，不修改支付宝/微信客户端，防封更安全
+ 免费、开源，无后门风险

## 原理

用户扫码付款 → 收款后手机通知栏出现提醒 → V免签监控端监听到提醒，推送至服务端 → 服务端根据金额匹配订单。

## 安装

**推荐方式（维护分支新增）**：上传代码后访问 `http://你的域名/install.php`，按向导完成环境检测、数据库配置（MySQL / SQLite 二选一）与自动建表，完成后**立即删除 install.php**。

**传统方式（宝塔面板）**：

1. 下载源代码，上传至网站目录
2. 宝塔面板新建网站：
   - 网站目录 → 运行目录设置为 `public` 并保存
   - 伪静态设置为 `thinkphp` 并保存
   - 默认文档将 `index.html` 放在第一行并保存
3. 打开 `config/database.php`，配置 MySQL 账号密码
4. 导入根目录的 `vmq.sql` 到数据库
5. 访问网站，默认后台账号密码均为 `admin`，**部署后请第一时间修改**

> 升级说明：直接下载新版本覆盖旧版本即可。

## 注意

+ 本系统原理是监控收款后手机的通知栏推送，请保持微信/支付宝/监控端后台运行，并加入内存清理白名单
+ 仅面向个人开发者，不适合商用多用户场景（商用请二次开发）
+ 监控端不兼容所有手机，异常时请更换手机或使用模拟器挂机
+ 免费开源、无收费计划，部署有一定技术门槛，请自行搜索文档
+ 手机端设置要点（以 MIUI 为例）：关闭神隐模式/应用省电限制、添加内存白名单、关闭 WLAN 优化、开启通知权限、微信关注「微信收款助手」公众号、支付宝开启「接收付款消息提醒」
+ 支持的通知类型：支付宝个人收款 / 商家二维码收款 / 店员通收款；微信二维码收款 / 店员收款 / 收款商业版
+ 若监听权限正常但仍不推送，请确认微信已关注「微信支付」「微信收款助手」两个公众号
